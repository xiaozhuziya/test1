# 下载

- [IndustrialHmi-source.zip](IndustrialHmi-source.zip)：源代码，使用 VS 打开解压后的 `IndustrialHmi.sln`。
- [IndustrialHmi-win-x64.zip](IndustrialHmi-win-x64.zip)：Windows x64 自包含运行包，解压全部文件后执行 `IndustrialHmi.App.exe`。

点击文件后，使用 GitHub 的 **Download raw file / 下载原始文件** 下载按钮。GitHub 不能在线预览 ZIP 是正常现象。

测试结果：36 项核心、模拟及本地 OPC UA 协议测试通过。Windows WPF 实际运行、真实汇川 PLC 和 PLC ST 编译仍需验证，见仓库 `docs/validation.md`。

运行 ZIP 作为下载交付物保存在本目录；后续版本可迁移至 GitHub Releases。
