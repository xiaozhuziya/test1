# 现场验收清单

先断开执行机构动力或使用仿真轴验证，再由具备资质的人员在受控条件下验证实际运动。本文件不把软件测试等同于设备安全认证。

1. **参数核对**：PLC 型号/固件、服务授权、端点、账户权限、证书指纹、节点地址/数据类型与机械单位逐项核对。节点错一个，应用应拒绝整批数据并禁用操作。
2. **输入对照**：逐个改变现场传感器，确认 UI 标签/地址/极性；断开网络时所有输入应显示未知。上位机位置/产量缓存不是实时反馈。
3. **手动条件**：自动模式、门打开、气压不足、急停、伺服报警/未就绪、设备非 Ready 任一条件均不得点动。
4. **点动**：先以最低速度验证方向和单位；按下运行、松开停止；反向互斥、速度上限、5 s 上限均验证。按住期间切页、Alt+Tab、失去鼠标捕获、关闭窗口均需停止请求。
5. **断网与崩溃**：运动时拔网线、停止 HMI 进程、冻结 HMI、断开交换机；无论 HMI 清零是否送达，PLC 必须在设定看门狗超时内撤销许可并执行经验证的停机。恢复网络不能自动恢复运动。
6. **气缸**：伸缩请求只能在允许条件生效；原位与到位信号正确；故障、超时、传感器矛盾及断电时的阀/机械行为由 PLC/气路设计明确，不能只依赖撤销请求位。
7. **自动模式**：Ready→Running→Paused→Running；故障/急停优先覆盖；恢复条件后仍须复位和重新启动，不能自动运动。CycleCount 只在实际完整周期完成后加一。
8. **机械保护**：实体急停、STO、轴正反限位、软限位、安全门联锁、气压保护和碰撞风险独立验证。
9. **证书与质量**：陌生/过期/主机名不匹配的证书不得自动接受；Bad/Uncertain 质量、未知节点、权限不足和错误类型必须阻止动作。
10. **验收记录**：记录项目版本、PLC 校验和/版本、配置、测试人、日期、每项实测结果和停止时间；现场通过前不要将本案例作为生产控制程序投用。
